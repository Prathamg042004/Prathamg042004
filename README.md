## Selected work

### [TokenSave ↗](https://github.com/Prathamg042004/tokensave)
**LLM cost optimization and developer tooling**

Caching, cost-aware model routing, and context optimization behind a JSON API, with a playground, documentation, and usage analytics.

**Built with:** Next.js · React · TypeScript · Supabase · Upstash Redis

[Live app](https://tokensave.vercel.app) · [Documentation](https://tokensave.vercel.app/docs) · [Source](https://github.com/Prathamg042004/tokensave)

### [TraceLedger ↗](https://github.com/Prathamg042004/traceledger)
**Business documents → structured records → human review**

A final-year project that links extracted fields to source evidence, validates business rules, reconciles related documents, and exports reviewed records. Includes a deterministic offline baseline and a separate live AI mode.

**Built with:** Next.js · JavaScript · AI SDK · PDF.js · Tesseract.js

[Source and demo guide](https://github.com/Prathamg042004/traceledger#five-minute-demo) · [Architecture](https://github.com/Prathamg042004/traceledger#architecture)
